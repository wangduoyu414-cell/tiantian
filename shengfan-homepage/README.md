# 晟帆国旅主页

北京晟帆国际旅行社有限公司（贵昌集团旗下）的展示主页和电子名片。面向党政机关、国央企客户，主推四项业务：红色教育、党政团建、企业团建、会务研学。

纯静态网站，不需要构建。手机和微信优先，电脑版同样完整。

## 本地预览

在终端里运行：

```bash
python3 /Users/zj/tiantian/shengfan-homepage/tools/serve.py 4350
```

启动后会打印两个地址：

- **电脑**：http://localhost:4350/
- **手机**：形如 http://192.168.0.40:4350/ 。手机要和这台 Mac 连在同一个网络，用 Safari 打开。

这个服务只提供 `index.html`、`assets/` 和 `design/`，其他文件一律 404。关掉终端窗口，服务就停了。

想连"了解贵昌集团"那个链接一起看，就改用上一级目录起服务，然后打开 http://localhost:4350/shengfan-homepage/ ：

```bash
python3 -m http.server 4350 --bind 127.0.0.1 --directory /Users/zj/tiantian
```

## 设计思路

- **风格层，贯穿全站**：界画工笔（界尺画屋宇，粗中细三级线宽，矿物色），宣纸底色，思源宋体标题，马善政毛笔字写题签和章名。
- **题材层，各章自己突出**：每章一张主画面，一个点缀色，由 CSS 变量 `--ac` 控制。
  - 红色教育：朱墨。
  - 团建：山野绿。
  - 会务研学：青蓝。
  - 北京资源：琉璃金。
- **北京地标**：集中出现在首屏《京华胜景图》和第四章导览图里。
- **图形**：全部用代码绘制（`assets/js/jh/` 界画库），再烘成图片按需加载；地图上的小画和题签是现画的矢量，任意缩放都清晰。照片到位前，照片位用画里的场景（灰度）占位。

## 字体

**v4 现状**：`index.html` 直接引用 Google Fonts（思源宋体 700/900、马善政），滑完整页约下载 2.5 MB 字体切片；在大陆网络和微信里常常连不上，这时会退回系统的宋体、楷体。上线前要按下面的办法自托管、只留用到的字，并给 `tools/fonts.py` 加上马善政。

只保留页面上用到的字。改了宋体文字（标题、名片姓名等）以后：

1. 在浏览器打开页面，在控制台运行 `tools/collect-serif-chars.js`，得到 700 和 900 两组字。
2. 弹层里的标题（证书名、问卷题目、地图站名）不在页面上，要手动补进 700 那组。
3. 更新 `tools/font-text.json`，运行 `python3 -X utf8 tools/fonts.py`。这一步需要能访问 Google Fonts。

## 问卷接收

问卷提交到 `/api/inquiry`（JSON）。接口不通时，页面会把需求整理好，让访客复制后发来，或者直接打电话，线索不会丢。

上线时可以复用奇米官网那套收件程序：`/Users/code/web-mingpian/deploy/` 里的 Python 小程序加 nginx 配置。它会把每条提交存进 CSV，并发邮件到指定邮箱，还可以推送到企业微信群。

## 合规要点

- 不用党徽、党旗、国徽、国旗。不画天安门城楼、天安门广场建筑群和新华门：长卷和中轴线经过这一段时只画线。

- 宣传册里"作为文化和旅游局的综合性服务商""全国顶尖高校资源"这类说法不用。大厂、航司、酒店的 logo 不做 logo 墙。

- 北京资源图只画站点和连线，不画北京轮廓和区界，属于示意线路图（参见《地图管理条例》第十五条）。拿不准的话，上线前送审。
