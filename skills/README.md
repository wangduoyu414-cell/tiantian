### 在另一台电脑的 Codex 中使用

1. 下载仓库或克隆后，将完整的 `skills/query-ctrip-mafengwo/` 文件夹复制到目标电脑用户主目录的 `.agents/skills/` 下。也可以放入目标项目的 `.agents/skills/`，作为项目技能。仓库顶层的 `skills/` 用于分发，并不等同于 Codex 的自动发现目录。目录与发现规则见 [OpenAI 官方说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。
2. 确认新电脑的 Codex 有可用的浏览器控制工具，能够读取动态页面、选择日期和展开产品。Skill 文件提供执行规则，不会自动复制浏览器工具或网站登录状态；新电脑按自己的工具说明和已有授权使用会话。
3. 在技能列表中确认可以发现该技能；未出现时按官方说明重启 Codex。调用示例：

   > 使用 $query-ctrip-mafengwo，只用携程查询上海虹桥康得思酒店的地址和电话，附来源和读取时间。

4. 首次使用再做一条日期报价检查：给出明确入住/离店日期、间数、成人和儿童条件，核对页面实际采用的条件、一个具体价案及其早餐/退改；缺失项保留未知。成功读取静态资料不等于动态报价也已验证。

运行不需要本仓库附带 Python、虚拟环境、固定选择器或爬虫脚本。原先用于验证技能格式的 Python/PyYAML 是开发检查工具，未作为运行依赖分发。原始聊天截图、本机路径、浏览器资料、登录数据和临时文件不在本包内。

### 工作范围

上游负责地区和交通方式选择、行程、预算分配及是否放宽条件；Skill 只按给定对象、条件和字段查询携程与马蜂窝。酒店、机票、火车票、景点、餐饮与攻略均按实际可读证据返回，不下单、不询价、不联系商家、不改网络设置。

输入可以是自然语言。仅缺少会影响答案的参数才补问；查电话不要求出行日期。默认每个独立查询目标预算为5分钟，可由调用方明确调整；换站、换词不重置预算。候选发现未指定数量时最多返回3项，不凑数。

返回含义分为 `query`（请求与实际条件）、`items`（事实和独立价案）、`evidence`（来源与时间）、`gaps`（缺口）、`coverage`（已查范围）、`status`（complete/partial/blocked）。条件匹配、页面销售状态、需求数量核验和任务完成度分别判断。

文旅政策、酒店官网、美团和大众点评是本窗口的探索记录，**不属于这个两站 Skill 的默认查询范围**。以下保留这些线索，供后续另行授权的查询使用。
